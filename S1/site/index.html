Activations exist for a reason.

With no nonlinearity a model can only draw a straight boundary, so it cannot separate two concentric rings. One ReLU hidden layer can — nothing else changes.

Depth without nonlinearity is a lie.

Depth without nonlinearity is a lie: five linear layers multiply into a single linear map, so a 5-layer linear net is no stronger than 1 layer — same line, same accuracy. Inserting ReLUs between the same five layers suddenly solves the ring.
