01 · The foundation

First, let every token look at every token.

02 · The serving bill

Same queries. Fewer keys to carry.

MHA, MQA, GQA, and MLA do not primarily change where attention looks. They change how much K/V state must travel with every generated token.

03 · The chronology

The field changes its mind.

Ordered by first public appearance. Same-day Transformer components follow the conceptual dependency: attention, then position.

04 · What the order reveals

It was never one bill.

A list makes these look like competing tricks. Dates reveal two alternating crises—and a field repeatedly changing which compromise it can tolerate.

The quadratic attention bill hurts training and long-prompt prefill. The linear KV-cache bill hurts autoregressive serving. The timeline zigzags because solving one does not solve the other.

Compute / lengthServing memoryRecover quality
201701

Exactness first

The Transformer removes recurrence and makes global lookup parallel. Position is the immediate missing piece. Nobody is trying to approximate attention yet; the win is that it works.

2019—2002

Length forces structure

Sparse patterns, routing, windows, and linear state all attack n². At the same moment MQA attacks a different bottleneck: reading cached keys and values one token at a time.

2021—2203

Approximation was not the only answer

RoPE and ALiBi improve position; the delta rule repairs lossy linear memory. Then FlashAttention keeps exact attention and changes the IO schedule. The field buys exactness back by respecting hardware.

202304

Context becomes a product feature

GQA shrinks serving state. NTK-aware scaling and YaRN stretch existing RoPE models. Attention sinks make bounded windows stream. The priority is no longer merely “train long”—it is “serve long now.”

202405

Memory comes back—compressed

MLA compresses the KV cache while DeltaNet and Gated DeltaNet improve fixed-size recurrent memory. Both are asking the same question: what is the smallest state that still retrieves?

202506

Selection becomes learned

NSA mixes overview, chosen detail, and locality; DSA learns a top-k indexer. DroPE makes the strangest move: use position to learn, then remove it to extrapolate. Scaffolding becomes disposable.

THE THING A LIST HIDES

The field did not march from “bad attention” to “better attention.” It oscillated between keeping every interaction exact and keeping only enough memory to survive. The likely next step is hybrid routing: cheap state for everything, learned selection for candidates, and exact attention only where uncertainty justifies the bill.

05 · Pick the trade

There is no winner. There is a workload.

Move the context dial. These are directional architectural costs—not benchmark claims or hardware promises.

SHORTLIST

01

Need exact retrieval?

Start dense. Use FlashAttention to make the exact algorithm IO-efficient; add GQA or MLA if serving memory is the bottleneck.

02

Need bounded streaming?

Sliding windows plus attention sinks give stable, fixed memory—but dropped history is truly gone unless an external memory restores it.

03

Need extreme length?

Sparse selection or recurrent linear state changes the asymptotics. Budget extra evaluation for missed evidence and finite-state collisions.

THE PATTERN

Exact → selective → compressed → stateful.

The next attention mechanism will probably not “solve” attention. It will decide which information deserves expensive exactness—and make the rest cheap.
